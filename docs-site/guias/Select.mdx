## Uso

Use o Select quando o usuário precisar escolher de uma lista pré-definida. A regra de corte: até 3 opções, use Radio; a partir de 4, use Select.

### Regras de layout

- O menu ocupa a **mesma largura** do campo de input.
- Altura máxima do menu: **240 px**, com rolagem pelo `ScrollArea` quando ultrapassar.
- Alinhamento segue as mesmas regras do **Input**: nunca mais largo que o container pai.

### Composição

- **Alert** ou mensagem de erro abaixo quando a validação falha.
- **Skeleton** no lugar do Select enquanto as opções carregam assincronamente.
- **Input** ou **NumberField** com `embedded`: o Select sem borda, fundo nem rótulo vai em `endAddon` ou `startAddon`, como seletor de unidade. A borda, o foco e o erro passam a ser do campo que o contém, e o nome acessível vem de `ariaLabel`. Só vale no modo simples.

## Formatação

```jsx
<!-- Single -->
<Select
  label="País"
  options={['Brasil', 'Argentina', 'Chile']}
  value={country}
  onChange={setCountry}
  placeholder="Selecione um país…"
/>

<!-- Multi -->
<Select
  label="Times"
  options={teams}
  value={selected}
  onChange={setSelected}
  multi
  placeholder="Selecione os times…"
/>

<!-- Não controlado -->
<Select label="Equipe" options={teams} defaultValue="Design" />
```

`size` aceita `sm` (32px de altura), `md` (40px, padrão) e `lg` (48px), as mesmas alturas do **Button**: um campo e um botão do mesmo tamanho ficam alinhados lado a lado. Texto em 13, 14 e 15px; recuo, ícones e botões internos acompanham. As opções da lista também acompanham o tamanho. Na seleção múltipla, os chips escolhidos usam o **Chip** `xs`, `sm` e `md`, para o campo manter a altura.

Sem `value`, o Select guarda a escolha por conta própria, partindo de `defaultValue`. Com `value`, quem controla é você: sem `onChange`, a escolha não muda.

### Teclado

- **↓ / ↑**: navega entre opções.
- **Enter**: seleciona a opção destacada.
- **Esc**: fecha o menu.
- **Backspace** (multi, campo vazio): remove o último chip.

## Guia de conteúdo

- Label: Sentence case, sem dois pontos. "País", "Time responsável".
- Placeholder: "Selecione um [item]…", nunca "Clique para selecionar".
- Opções: consistentes no estilo, todas substantivos ou todas verbos, nunca misturadas.
- Multi: placeholder some quando há chips; não repita o label no placeholder.
- Estado vazio de busca: "Nenhuma opção encontrada", neutro, sem sugestão de digitação errada.

## Guia de design

**Tokens.** Borda idle `--ob-border`, focus `--ob-blue` + ring `--ob-focus-ring`. Menu sombra `0 8px 24px rgba(0,0,0,.12)`. Chips fundo `--ob-blue-100`, texto `--ob-blue-700`.

**Motion.** Caret gira 180° com transição de 150ms. Borda e ring: 150ms `--ob-ease`. Dropdown aparece instantaneamente, sem animação de entrada, para parecer responsivo.

**Foco.** O anel de foco aparece enquanto o campo tem foco ou o menu está aberto. Depois de escolher uma opção na seleção única, o menu fecha e o foco permanece no campo, para o teclado continuar funcionando (`Enter` ou `↓` reabrem).

**Estados.** Idle → Focus (border + ring) → Filled → Disabled (opacity 60%, cursor not-allowed) → Error (border danger + mensagem abaixo).

**Multi.** O campo cresce verticalmente para acomodar chips, nunca trunca. Chip tem botão × para remoção individual.

<Nota>

**Acessibilidade:** use `role="combobox"`, `aria-expanded`, `aria-autocomplete="list"`. Opções com `role="option"` e `aria-selected`. O grupo deve ter `aria-label` descritivo.

</Nota>
