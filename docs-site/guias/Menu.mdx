## Uso

Use para uma lista de ações ou opções que abre de um gatilho: botão "…", avatar, ícone de coluna. Cobre desde a
lista plana de ações até radio, checkbox, busca, contas e submenus.

Duas formas de abrir: **`Menu`**, ancorado a um gatilho clicado; **`ContextMenu`**, que envolve uma área e
abre no clique direito (ou Shift+F10).

## Composição

**Ph** (ícones), **Checkbox**/**Radio**/**Switch** (itens desses tipos, embutidos e `inert`), **Avatar**/
**Badge** (contas), **SearchInput** (busca), **List/ListItem/ListSubheader/ListDivider** (anatomia da linha).

## Formatação

```jsx
<Menu
  trigger={<Button kind="secondary" icon={<Ph n="dots-three" size={16} />}>Ações</Button>}
  items={[
    { label: 'Editar', icon: 'pencil-simple', shortcut: 'Ctrl+E' },
    { label: 'Duplicar', icon: 'copy' },
    { type: 'separator' },
    { label: 'Excluir', icon: 'trash', tone: 'danger' },
  ]}
/>
```

## Guia de conteúdo

- Rótulo do item é um verbo de ação curto: "Duplicar", não "Duplicar item".
- Atalho (`shortcut`, desenhado pelo **Kbd**) só quando existe de verdade no teclado, não é decoração.

## Guia de design

**Estados do item.** Padrão, destacado (mouse ou teclado), desabilitado, submenu aberto. Item selecionado
(`option`/conta atual) mostra um check à direita.

**Contas.** O item `type: 'account'` mostra o **Avatar** com `name` e `email`. Passe `src` para a foto da pessoa; sem foto, ou se ela não carregar, aparecem as iniciais do nome, que `initials` pode trocar. A foto é decorativa, porque o nome já está escrito ao lado.

**Camada.** O painel abre no `body`, na camada `--ob-z-dropdown`, preso ao gatilho. Por isso ele não é cortado dentro de um Modal, Drawer, Accordion, Table ou área com rolagem. `placement` escolhe o lado e o painel vai para o lado oposto quando falta espaço; Esc fecha só o menu.

**Comportamento ao escolher.** Ação simples, seleção única e conta fecham o menu; radio, checkbox e toggle
mantêm o menu aberto, a pessoa pode marcar vários antes de fechar.

**Um item, uma parada de foco.** Componentes embutidos (Checkbox, Radio, Switch) ficam `inert`: o item
recebe clique e teclado, o componente só mostra o estado.

**Conteúdo livre.** `{ type: 'custom', content, ariaLabel }` encaixa um bloco qualquer (por exemplo um `Tabs`
`pill` para escolher a aparência) entre os itens. O bloco não é item: as setas, Home, End e a digitação o
pulam, e dentro dele o teclado é o do próprio conteúdo (Tab e Shift+Tab percorrem os controles). Esc fecha o
menu, e sair do bloco com Tab para fora do painel também fecha. Prefira os tipos prontos (`radio`, `toggle`)
quando bastam; use o bloco quando o controle não existe como item.

**`defaultOpen`.** Monta o painel já aberto, sem esperar o clique, só para demonstrações e capturas de tela;
em produto o menu sempre começa fechado.
