## Uso

Filtros por período, prazos, agendamentos. O campo é a entrada principal: o usuário pode **digitar** a data ou abrir o calendário pelo botão à direita.

### Modos

- **single** (padrão): uma data. `value`, `defaultValue` e `onChange` trabalham com `Date`; `onChange` recebe `null` quando o campo é esvaziado.
- **range**: dois campos (início e fim) e um único calendário. `value`, `defaultValue` e `onChange` trabalham com `{ start, end }`. O calendário fecha ao escolher o fim.

<FacaEvite>
<Faca>

Permitir digitação além do calendário, e restringir as datas com `min`, `max` e `isDateDisabled`: o campo mostra "Data indisponível" se o valor digitado não for permitido.

</Faca>
<Evite>

Campo de data para datas muito distantes, como nascimento: o usuário precisaria voltar muitos meses no calendário. Aceite só a digitação, com um **Input**.

</Evite>

## Formatação

```jsx
const [entrega, setEntrega] = useState(null);
<Datepicker label="Entrega" value={entrega} onChange={setEntrega} min={new Date()} />

const [periodo, setPeriodo] = useState({ start: null, end: null });
<Datepicker mode="range" label="Período" value={periodo} onChange={setPeriodo} />
```

<Nota>

O Datepicker usa o **Calendar** e o **Popover**. Regras de calendário (`min`, `max`, `isDateDisabled`, `weekStartsOn`) são repassadas e valem também para a digitação.

</Nota>

## Guia de conteúdo

- Formato `dd/mm/aaaa` (pt-BR), com máscara automática.
- Rótulo curto e específico: "Data de entrega", "Período da campanha".
- Mensagens de erro do campo: "Data inválida" (31/02), "Data indisponível" (fora de `min`/`max` ou desabilitada), "Deve ser após a data inicial" (fim antes do início).
- Use `hint` para explicar a regra antes do erro: "Fins de semana ficam indisponíveis".

## Guia de design

**Tokens.** Campo no `FieldShell`, como o **Input**; botão de calendário é o **Button** neutro só com ícone; o popover é o **Popover**, com o **Calendar** dentro (dia selecionado `--ob-blue`, intervalo `--ob-blue-100`).

**Foco.** O campo inteiro mostra o anel de foco enquanto qualquer parte dele (digitação ou calendário) tem foco.

<Nota>

**Versão mobile:** o popover ancorado não substitui um seletor nativo em telas pequenas. Por isso o componente **não marca** "versão mobile".

</Nota>
