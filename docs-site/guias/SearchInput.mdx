## Uso

Use quando o usuário precisa localizar conteúdo: tarefas, integrações, documentos. Pode operar em modo local (filtra lista em memória) ou assíncrono (dispara requisição com debounce).

### Quando usar

- Barra global de busca na topbar.
- Filtro inline de listas e tabelas.
- Seleção de item em um campo de autocomplete.

### Composição com outros componentes

- **Skeleton** nas linhas do dropdown durante loading assíncrono.
- **Badge** para indicar filtros ativos.
- **Tooltip** no botão de limpar: "Limpar busca".

## Formatação

Altura padrão 44px. Ícone de lupa fixo à esquerda. Spinner substitui o ícone durante loading. Botão ×-círculo aparece quando há texto. Dropdown flutua abaixo com `z-index: var(--ob-z-dropdown)` (camada *dropdown* da escala de layers).

```jsx
<SearchInput
  value={q}
  onChange={setQ}
  placeholder="Buscar tarefas…"
  loading={fetching}
  results={results}   // string[] ou {label, ...}[]
  onSelect={handleSelect}
  width={320}
/>
```

## Guia de conteúdo

- Placeholder: "Buscar [contexto]…", ex: "Buscar tarefas…", "Buscar integrações…".
- Estado vazio de resultados: "Nenhum resultado para '[query]'".
- Recentes: "Buscas recentes" como kicker da lista de sugestões iniciais.
- Evite "Digite para buscar" no placeholder: é óbvio demais.

## Guia de design

**Tokens.** Borda idle `--ob-border`, focus `--ob-blue` + ring `--ob-blue-100`. Fundo `--ob-surface`. Dropdown sombra `--ob-shadow-lg`.

**Motion.** Borda e ring: transição 150ms `--ob-ease`. Spinner: rotação contínua 0.8s linear. Dropdown: sem animação, aparece instantaneamente para parecer responsivo.

**Debounce.** Para buscas assíncronas, aplique debounce de 300ms no `onChange` antes de disparar a requisição.

<Nota>

**Acessibilidade:** aplique `role="combobox"`, `aria-expanded` e `aria-autocomplete="list"`. Resultados devem ter `role="option"` e ser navegáveis por ↑/↓.

</Nota>
