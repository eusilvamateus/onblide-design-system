## Uso

Use quando o usuário precisa filtrar ou localizar conteúdo: tarefas, integrações, documentos. O campo só captura o texto; quem filtra a lista ou dispara a requisição é a aplicação, no `onChange`.

### Quando usar

- Barra global de busca na topbar.
- Filtro inline de listas e tabelas.
- Busca dentro de um Menu (prop `search`).

<FacaEvite>
<Faca>

Use `loading` enquanto uma busca assíncrona está em andamento, e dê o nome acessível por `ariaLabel` quando não houver rótulo visível.

</Faca>
<Evite>

Usar o SearchInput para mostrar sugestões ou escolher um item de uma lista: para isso existe o **Autocomplete**. Também não o reutilize como campo de formulário genérico: ele sinaliza "busca", e para outros textos há o **Input**.

### Composição com outros componentes

- **Navbar**: campo central no layout de busca.
- **Menu**: busca dentro de listas longas de comandos.
- **Table** e **TreeView**: o filtro fica fora, no SearchInput acima do componente.

## Formatação

Altura padrão 44px. Ícone de lupa fixo à esquerda. O carregamento usa o **Spinner** `sm`, no mesmo espaço do botão de limpar, para o texto não mudar de largura. O botão de limpar (**Button** neutro só com ícone) aparece quando há texto.

```jsx
<SearchInput
  value={q}
  onChange={setQ}
  placeholder="Buscar tarefas…"
  loading={fetching}
  width={320}
/>
```

## Guia de conteúdo

- Placeholder: "Buscar [contexto]…", ex: "Buscar tarefas…", "Buscar integrações…".
- Evite "Digite para buscar" no placeholder: é óbvio demais.

## Guia de design

**Tokens.** Campo no `FieldShell`, como o **Input**: borda idle `--ob-border`, foco `--ob-blue` com o anel de foco. Fundo `--ob-surface`.

**Motion.** Borda e anel: transição de 150ms `--ob-ease`. Indicador de carregamento: rotação contínua de 0.8s linear.

**Debounce.** Para buscas assíncronas, aplique debounce de 300ms no `onChange` antes de disparar a requisição.

<Nota>

**Acessibilidade:** o campo tem `role="searchbox"` e nome acessível (`ariaLabel`, padrão "Buscar"); o botão de limpar tem `aria-label="Limpar"`.

</Nota>
