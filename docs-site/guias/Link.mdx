## Uso

Navegar entre páginas ou destinos. Para ações use `Button` (ghost). Links externos ganham ícone automático.

## Formatação

```jsx
<Link href="/docs">Documentação</Link>
<Link external href="…">Repositório</Link>
```

## Guia de conteúdo

- Texto descreve o destino: "Documentação", não "clique aqui".
- Inline dentro de frases, em fluxo natural.

## Guia de design

**Cor (`tone`).** `primary` (padrão, `--ob-blue`), `neutral` (`--ob-fg`, para links no meio do texto corrido) e `muted` (`--ob-fg-soft`, para links secundários como "Esqueci minha senha"). Sublinhado no hover. O vocabulário de `tone`, `appearance` e `variant` é o mesmo em todo o design system: veja [Vocabulário das props](/fundacoes/vocabulario-das-props).

**Motion.** Transição de cor 120ms; sublinhado aparece no hover.

**Tamanho.** O link herda o tamanho e a fonte do texto ao redor; para mudar, ajuste o contêiner.

**Responsivo / mobile.** Herda tamanho do texto; alvo de toque confortável inline.
