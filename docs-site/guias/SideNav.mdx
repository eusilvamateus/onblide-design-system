## Uso

Use em dashboards e aplicações com 4–8 seções de nível superior. Para produtos mobile-first com menos de 5 seções, prefira uma tab bar inferior.

### Estados

- **Expandido** (240px): logo + rótulos + badges + conta no rodapé. Com `onToggle`, um botão circular fica na borda direita da barra para recolhê-la.
- **Colapsado** (72px): só ícones e dot badge. A logo vira o botão de abrir quando o mouse passa por cima dela. O título do item revela o rótulo no hover.
- **flush**: sem borda/borderRadius próprios; integra ao shell do app. Recolhida, mantém os 72px.

### Composição com outros componentes

- **Tooltip** em cada item no modo colapsado (rótulo no hover).
- **Badge** para contagem de notificações: dot no colapsado, número no expandido.
- **Avatar** no rodapé, com o nome da pessoa e uma linha secundária (e-mail ou cargo).
- **Menu** no rodapé de conta: Perfil, Configurações e Sair (`onProfile`, `onSettings`, `onSignOut`, ou `accountMenu` para itens próprios). Abre para cima na barra expandida e para o lado na recolhida.

## Formatação

```jsx
<SideNav
  items={[
    { id: 'home',     label: 'Início',   icon: 'house' },
    { id: 'tasks',    label: 'Tarefas',  icon: 'kanban', badge: 3 },
    { section: 'Config' },
    { id: 'settings', label: 'Ajustes',  icon: 'gear' },
  ]}
  active={route}
  onNav={setRoute}
  collapsed={collapsed}
  onToggle={() => setCollapsed(c => !c)}
  flush
/>
```

Item de seção: `{ section: 'Rótulo' }`, renderiza um kicker mono entre grupos de itens.

## Guia de conteúdo

- Rótulos: substantivos curtos. "Início", "Tarefas", "Métricas", nunca verbos ("Ver tarefas").
- Kickers de seção: mono maiúsculo, máximo 2 palavras. "Workspace", "Config".
- Badges: máximo 2 dígitos. Acima de 99, mostre "99+".
- Rodapé: nome da pessoa em `accountName` e, em `accountDetail`, e-mail ou cargo.
- Marca: a logo horizontal vai em `brand` e o símbolo, em `brandMark` (recolhida); nunca o nome da marca em texto. Sem logo, use `hideBrand`: o botão de abrir continua no topo da barra recolhida.

## Guia de design

**Tokens.** Item ativo: fundo `--ob-blue-100`, texto `--ob-blue-700`, pip `--ob-blue`. Hover: `--ob-bg-warm`. Fundo geral `--ob-surface`.

**Motion.** Transição de `background` a 120ms (`--ob-ease`) nos itens. A animação de expand/collapse (width) deve ser implementada no shell pai: o componente usa `width` calculado e não anima internamente para não conflitar com o layout do grid.

**Responsivo.** Em viewports \< 768px, use o modo colapsado como padrão. Abaixo de 480px, converta para drawer (overlay) com backdrop clicável.

<Nota>

**Versão mobile:** SideNav não atende mobile diretamente, substitua por tab bar inferior ou drawer. Por isso não marca "versão mobile" na matriz.

</Nota>
