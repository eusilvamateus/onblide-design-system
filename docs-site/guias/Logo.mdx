## Variantes de arquivo

O componente acima é a forma horizontal com cor de tema. Para fora do produto, a marca tem mais duas formas:
**empilhada** e **símbolo**. Cada uma em três cores fixas: **primary**, **white**, **dark**, nos arquivos de
`docs-site/marca/`. Uso de cada uma, escolha de cor e área de proteção: [Fundações › Marca](../../fundacoes/marca).
