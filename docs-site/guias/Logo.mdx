## As outras variantes da marca

O componente acima é só a forma **horizontal** com cor de tema — para dentro do produto. A marca Onblide tem
mais duas formas (**empilhada** e **símbolo**) e três cores fixas por arquivo (**primary**, **white**, **dark**),
para usar fora do produto: apresentações, documentos, redes sociais, favicon, impressos. Nenhuma delas é uma
substituta da outra — cada uma é a certa para um contexto.

### Horizontal — uso padrão

Símbolo e nome lado a lado. Primeira opção sempre que houver largura disponível.

### Como escolher a cor

- **primary** — padrão sobre fundo claro (branco, `--ob-surface`, cinza muito claro).
- **white** — sobre fundo escuro ou sobre uma cor de marca saturada (ex.: um card azul).
- **dark** — sobre fundo claro mas não branco puro (creme, bege, papel).

### Área de proteção e tamanho mínimo

- Espaço livre ao redor de no mínimo a altura do símbolo — nenhum texto, borda ou elemento entra nessa margem.
- Tamanho mínimo legível: horizontal a partir de 20px de altura; empilhada a partir de 48px; símbolo a partir
  de 16px (favicon).
- Nunca redesenhe, recolora fora das três variantes, distorça a proporção ou separe o símbolo do nome.
