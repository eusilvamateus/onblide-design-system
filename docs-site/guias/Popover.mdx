## Uso

Use para conteúdo maior que um `Tooltip` mas que não precisa bloquear a tela como um `Modal` — um filtro
curto, uma prévia com ações, um formulário pequeno. Dois modos de interação:

- **`click`** (padrão) — abre/fecha no gatilho, foco vai para o primeiro campo ou botão (papel `dialog`).
- **`hover`** — abre 300ms depois do mouse entrar (ou ao focar), fecha 150ms depois de sair (papel `tooltip`);
  use só para conteúdo que não precisa de interação (uma prévia, um resumo).

## Composição

**FloatingPanel** (superfície), **Ph** (botão de fechar). No conteúdo: qualquer combinação — `Checkbox`,
`Input`, `Switch`, `List`, `Avatar`, `Badge`.

## Formatação

```jsx
<Popover trigger={<Button kind="secondary">Filtrar</Button>} title="Filtrar por status">
  <Checkbox label="Em andamento" checked onChange={setA} />
  <Checkbox label="Concluída" checked={false} onChange={setB} />
</Popover>
```

## Guia de conteúdo

- `title` é o nome da tarefa ("Filtrar por status"), não um rótulo genérico ("Opções").
- `footer` é para ações que fecham ou aplicam algo ("Aplicar", "Limpar") — não repita o botão de fechar do título.

## Guia de design

**Posição.** `placement` troca para o lado oposto quando falta espaço, e o popover se mantém 8px dentro da
tela; `align` (`start`/`center`/`end`) posiciona ao longo do eixo perpendicular.

**Fechamento.** Esc (foco volta ao gatilho), clique fora, botão de fechar, ou foco saindo do popover e do
gatilho.
