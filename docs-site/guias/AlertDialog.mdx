## Uso

Antes de uma ação que não dá para desfazer ou que afeta outras pessoas: excluir, publicar, sair sem salvar. O usuário só segue depois de decidir; não há botão de fechar no cabeçalho, mas Esc e o backdrop cancelam, exceto enquanto a confirmação está em andamento (`loading`).

### Quando usar

- **default**: confirmações neutras ("Publicar as alterações?").
- **danger**: ações destrutivas ("Excluir projeto?"). O botão de confirmar fica vermelho.

Título como pergunta direta e botões com verbos específicos: "Excluir projeto", "Manter".

### Composição

O AlertDialog é um **Modal** (`size="sm"`, `role="alertdialog"`, sem botão de fechar) com dois **Button** no rodapé. O foco inicial vai para o botão de cancelar.

## Formatação

```jsx
const [aberto, setAberto] = useState(false);
const [excluindo, setExcluindo] = useState(false);

const confirmar = async () => {
  setExcluindo(true);
  try {
    await excluir();
    setAberto(false);
  } finally {
    setExcluindo(false);
  }
};

<AlertDialog
  open={aberto}
  loading={excluindo}
  onClose={() => setAberto(false)}
  onConfirm={confirmar}
  tone="danger"
  title="Excluir projeto?"
  confirmLabel="Excluir projeto"
>
  Esta ação não pode ser desfeita. Todas as tarefas serão removidas.
</AlertDialog>
```

<Nota>

`onConfirm` não fecha o diálogo: quem usa decide quando fechar, por exemplo depois de a requisição terminar. Enquanto
ela roda, passe `loading`: o botão de confirmar mostra o carregamento e ignora novos cliques, o de cancelar fica
desabilitado, e Esc e o backdrop não fecham. Assim a ação não é enviada duas vezes nem abandonada no meio.

</Nota>

## Guia de conteúdo

- Título: a pergunta, em uma frase ("Excluir projeto?").
- Corpo: a consequência, em linguagem direta ("Esta ação não pode ser desfeita.").
- Botões: o verbo da ação no confirmar e "Cancelar" (ou "Manter") no outro.

## Guia de design

**Tokens.** Herda o **Modal**: superfície `--ob-surface`, fundo `--ob-scrim`, sombra `--ob-shadow-lg`. O botão destrutivo usa `--ob-danger`.

**Camada.** Herda a do **Modal** (`--ob-z-modal`), então uma confirmação aberta a partir de um Drawer aparece na frente dele.

**Acessibilidade.** O corpo é a descrição acessível do diálogo (`aria-describedby`), e leitores de tela o anunciam junto com o título.
