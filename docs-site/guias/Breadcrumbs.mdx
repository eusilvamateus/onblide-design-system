## Uso

Use em telas com três ou mais níveis de profundidade (Cliente › Projeto › Peça), quando a `Sidebar` só mostra
o primeiro nível e o usuário precisa voltar rápido a qualquer ponto do caminho.

<FacaEvite>
<Faca>

Primeiro item só com ícone (`icon` + `ariaLabel`, sem `label`) quando ele for a raiz ("Início").

</Faca>
<Evite>

Usar em telas com um ou dois níveis. Nesse caso um botão "Voltar" já resolve.

</Evite>
</FacaEvite>

## Composição

- **Ph** para o separador (`caret-right`) e os ícones dos itens.
- **Menu** para o menu "…" quando `maxItems` recolhe o meio da trilha.

## Formatação

```jsx
<Breadcrumbs
  items={[
    { icon: 'house', ariaLabel: 'Início' },
    { label: 'Clientes' },
    { label: 'Padaria Estrela' },
  ]}
/>
```

## Guia de conteúdo

- Rótulo é o nome real do item (nome do cliente, do projeto), nunca genérico ("Página").
- Rótulos longos cortam em 220px com reticências; o texto completo fica no `title` (tooltip nativo).

## Guia de design

**Tokens.** Links em `--ob-fg-soft`, hover/atual em `--ob-fg-strong`, separador em `--ob-fg-mute`. Fundo do
hover: `--ob-surface-2`.

**Recolhimento.** Com `maxItems`, mantém o primeiro item e os últimos `maxItems - 1`; o meio vira um Menu
aberto pelo botão "…".

**Responsivo.** Quebra linha em vez de rolar horizontalmente quando falta espaço.
