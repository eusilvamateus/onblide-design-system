## Uso

Use só em telas de edição densas (editor de peças, planilha) — não é navegação de página: para isso, `Tabs`
ou `SideNav`. Sem fundo próprio; quem usa decide onde a barra fica (cabeçalho de editor, janela, toolbar).

<Faca>

Reaproveitar os mesmos tipos de item do `Menu` (checkbox, radio, submenu) entre os menus da barra.

## Formatação

```jsx
<Menubar
  ariaLabel="Menu do editor"
  menus={[
    { label: 'Arquivo', items: [{ label: 'Novo', shortcut: 'Ctrl+N' }] },
    { label: 'Editar', items: [{ label: 'Desfazer', shortcut: 'Ctrl+Z' }] },
  ]}
/>
```

## Guia de design

**Próprio do Menubar.** Os menus são irmãos: com um aberto, passar o mouse sobre outro gatilho troca sem
clicar. ← e → movem entre gatilhos na barra e, com um menu aberto, passam para o vizinho.

**Teclado.** A barra é uma parada só de Tab (roving tabindex, `role="menubar"`); ↓/Enter/Espaço abrem o menu
e destacam o primeiro item; Home/End vão ao primeiro/último gatilho.
