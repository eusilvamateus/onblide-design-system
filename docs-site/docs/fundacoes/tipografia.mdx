Três famílias, cada uma com um trabalho:

- **Poppins** (`--ob-font`) é a base: interface, títulos e corpo.
- **Playfair Display** (`--ob-font-serif`) é o acento editorial, em itálico, usada com parcimônia.
- **JetBrains Mono** (`--ob-font-mono`) é para código, tokens e rótulos pequenos.

```jsx live
<div style={{ display: 'grid', gap: 8, padding: 16 }}>
  <div style={{ fontFamily: 'var(--ob-font)', fontSize: 32, fontWeight: 800, letterSpacing: '-0.03em' }}>Poppins, o texto da interface</div>
  <div style={{ fontFamily: 'var(--ob-font-serif)', fontSize: 28, fontStyle: 'italic' }}>Playfair Display, o acento editorial</div>
  <div style={{ fontFamily: 'var(--ob-font-mono)', fontSize: 14 }}>JetBrains Mono: --ob-blue: #0a4ee4;</div>
</div>
```
