Fundações são os **design tokens**: variáveis CSS com prefixo `--ob-` que guardam cores, tipografia, espaçamentos,
raios, sombras e movimento. Componentes e páginas os consomem; ninguém escreve valor solto.

A fonte única é o arquivo `tokens.css` do pacote, e as tabelas destas páginas são geradas dele, então nunca ficam
desatualizadas. Cada tabela mostra o valor no tema claro e, quando muda, no escuro.

| Fundação | O que define |
|---|---|
| [Cores](./cores) | Paleta da marca, neutros e cores semânticas. |
| [Tipografia](./tipografia) | Famílias, pesos, escala de tamanhos e entrelinhas. |
| [Espaçamento](./espacamento) | Escala de 4 px e apelidos por intenção. |
| [Raios](./raios) | Arredondamento de cartões, botões e campos. |
| [Sombras](./sombras) | Elevação nos temas claro e escuro. |
| [Camadas e opacidade](./camadas-e-opacidade) | Ordem de empilhamento e escalas de transparência. |
| [Breakpoints](./breakpoints) | Larguras de referência para layouts responsivos. |
| [Movimento](./movimento) | Durações e curvas de animação. |
| [Iconografia](./iconografia) | Phosphor, o registro `Icons` e as marcas. |
| [Marca](./marca) | Logo e variações. |
