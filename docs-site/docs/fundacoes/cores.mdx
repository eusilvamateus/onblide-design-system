Cinco cores carregam o sistema inteiro: **azul** é a voz da marca (ação principal, links, foco), **verde** é só
sucesso, **laranja** é aviso e acento, **tinta** é o texto e **creme** é uma sobreposição de calor, nunca o fundo da página.
