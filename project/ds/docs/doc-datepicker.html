Datepicker doc

Seleção de data única ou intervalo, com entrada manual mascarada e calendário popup.

✓ Tem guia de uso
✓ Tem guia de conteúdo
✓ Usa os design tokens
✓ Possui motion
✓ Possui versão web
✓ Possui versão responsiva
– Possui versão mobile

1 · Uso

Filtros por período, agendamentos, prazos. Modo singleDate para uma data; padrão é intervalo (de/até).

✓ Faça

Permitir digitação além do calendário.

✕ Evite

Calendário-only para datas distantes (ex: nascimento).

2 · Formatação

<Datepicker singleDate startDateLabel="de"
  endDateLabel="até" maxBookingDays={90}
  values={v} onChange={setV} onSubmit={fn} />
PropTipoPadrão
singleDatebooleanfalse
values{startDate,endDate}null
maxBookingDaysnumber30
showSubmitButtonbooleantrue

3 · Guia de conteúdo

  • Formato dd/mm/yyyy (pt-BR).
  • Labels curtos: "de", "até".
  • Erros claros: "Data inválida", "Deve ser após data inicial".

4 · Guia de design

Tokens. Inputs como Input; dia selecionado --ob-blue, intervalo --ob-blue-100. Popup --ob-shadow-md.

Motion. Popup com fade; transições de hover nos dias.

Versão mobile: o calendário de duas colunas e o popup ancorado não cabem bem em telas pequenas. Em mobile, use um seletor full-screen nativo ou stepper. Por isso não marca "versão mobile".
