1 · Uso

Navegar entre páginas ou destinos. Para ações use Button (ghost). Links externos ganham ícone automático.

2 · Formatação

<Link href="/docs">Documentação</Link>
<Link external href="…">Repositório</Link>
PropTipoPadrão
variantdefault|subtle|quietdefault
externalbooleanfalse

3 · Guia de conteúdo

  • Texto descreve o destino: "Documentação", não "clique aqui".
  • Inline dentro de frases, em fluxo natural.

4 · Guia de design

Tokens. --ob-blue (default), --ob-fg (subtle), --ob-fg-soft (quiet). Sublinhado no hover.

Motion. Transição de cor 120ms; sublinhado aparece no hover.

Responsivo / mobile. Herda tamanho do texto; alvo de toque confortável inline.
