Radio doc

Escolha única entre opções mutuamente exclusivas. Use RadioGroup para o conjunto.

Possui motion

1 · Uso

2–6 opções visíveis onde só uma vale. Para muitas opções, prefira Select. Cada opção pode ter descrição.

2 · Formatação

<RadioGroup value={v} onChange={setV} options={[
  {value:'pro', label:'Pro', description:'…'}
]} />
PropTipoPadrão
options{value,label,description,disabled}[]—
valuestring—

3 · Guia de conteúdo

  • Labels paralelos e curtos.
  • Descrição opcional explica a diferença entre opções.

4 · Guia de design

Tokens. Anel --ob-blue quando marcado; borda --ob-border quando vazio.

Motion. Transição de borda 160ms ao selecionar.

Responsivo / mobile. Alvo de toque ≥44px na linha inteira (label clicável).
