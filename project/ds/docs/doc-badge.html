Badge doc

Rótulo compacto de status ou categoria. Pílula com ponto colorido + texto.

✓ Tem guia de uso
✓ Tem guia de conteúdo
✓ Usa os design tokens
– Possui motion
✓ Possui versão web
✓ Possui versão responsiva
✓ Possui versão mobile

1 · Uso

Comunica estado (ativo, pendente, erro) ou tag. Não é clicável — para filtros use chips.

  • blue em foco · green sucesso · orange atenção · red erro · grey neutro.

2 · Formatação

<Badge tone="green">Ativo</Badge>
<Badge tone="orange">Pendente</Badge>
PropTipoPadrão
toneblue|green|orange|red|greyblue

3 · Guia de conteúdo

  • 1–2 palavras. Substantivo de estado: "Ativo", "Rascunho".
  • Sentence case.
  • Cor segue semântica — verde só para positivo, vermelho só para erro.

4 · Guia de design

Tokens. Fundo --ob-*-100, texto --ob-*-700, ponto --ob-*. Raio pílula 999px.

Motion. Estático — sem animação. (não marca motion na matriz)

Responsivo / mobile. Tamanho fixo, funciona em qualquer viewport.
