1 · Uso

Várias escolhas independentes, ou um aceite ("Li os termos"). Use indeterminate no pai de uma lista parcialmente marcada.

2 · Formatação

<Checkbox checked={v} indeterminate={some}
  onChange={setV} label="Selecionar tudo" />
PropTipoPadrão
checkedboolean—
indeterminatebooleanfalse

3 · Guia de conteúdo

  • Label afirmativo: "Enviar resumo diário".
  • Descrição opcional para detalhes.

4 · Guia de design

Tokens. Preenchido --ob-blue com check branco; raio 6px.

Motion. Transição de preenchimento 160ms.

Responsivo / mobile. Linha inteira clicável, alvo ≥44px.
