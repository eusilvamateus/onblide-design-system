Modal doc

Diálogo que interrompe o fluxo para uma decisão ou foco. Backdrop escurecido + Esc para fechar.

✓ Tem guia de uso
✓ Tem guia de conteúdo
✓ Usa os design tokens
✓ Possui motion
✓ Possui versão web
✓ Possui versão responsiva
✓ Possui versão mobile

1 · Uso

Reserve para ações que exigem foco total: confirmações destrutivas, formulários curtos, detalhes. Não empilhe modais.

✓ Faça

Ação primária + cancelar no footer.

✕ Evite

Modal para informação não-bloqueante (use toast).

2 · Formatação

<Modal open={o} onClose={fn} title="Excluir?"
  footer={<>…</>}>Conteúdo</Modal>
PropTipoPadrão
openboolean—

widthnumber440

3 · Guia de conteúdo

  • Título é uma pergunta ou ação: "Excluir projeto?".
  • Corpo explica a consequência em 1–2 frases.
  • Botão confirma com o verbo, não "OK".

4 · Guia de design

Tokens. Card --ob-surface + --ob-shadow-lg; backdrop escurecido com blur. Raio 16px.

Motion. Backdrop fade 160ms; card com spring --ob-ease-spring (200ms).

Responsivo / mobile. Largura limitada com margem; em mobile vira folha de largura total. Esc e toque no backdrop fecham.
