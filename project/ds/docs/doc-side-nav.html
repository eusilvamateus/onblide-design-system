Side Navigation doc

Rail de navegação lateral que organiza as seções principais de uma aplicação. Expande (240px, rótulos visíveis) e colapsa (72px, só ícones). Em modo flush, integra-se ao layout de aplicação sem borda própria. Compõe com Tooltip, Badge e Avatar.

1 · Uso

Use em dashboards e aplicações com 4–8 seções de nível superior. Para produtos mobile-first com menos de 5 seções, prefira uma tab bar inferior.

Estados

  • Expandido (240px) — logo + rótulos + badges + workspace no rodapé.
  • Colapsado (72px) — logo some, ícones, dot badge, botão expandir no topo. Tooltip revela o rótulo no hover.
  • flush — sem borda/borderRadius próprios; integra ao shell do app.
Faça

Marque só um item ativo por vez. Use badges numéricos para alertas não lidos — máximo 3 itens com badges simultâneos.

Evite

Mais de 8 itens no nível superior. Itens que não mapeiam uma rota — ações pertencem a botões, não à nav.

Composição com outros componentes

  • Tooltip em cada item no modo colapsado (rótulo no hover).
  • Badge para contagem de notificações — dot no colapsado, número no expandido.
  • Avatar no rodapé para o perfil do workspace.
  • Dropdown ao clicar no rodapé: "Configurações", "Sair".

3 · Guia de conteúdo

  • Rótulos: substantivos curtos. "Início", "Tarefas", "Métricas" — nunca verbos ("Ver tarefas").
  • Kickers de seção: mono maiúsculo, máximo 2 palavras. "Workspace", "Config".
  • Badges: máximo 2 dígitos. Acima de 99, mostre "99+".
  • Workspace no rodapé: nome da empresa ou produto, não do usuário.

4 · Guia de design

Tokens. Item ativo: fundo --ob-blue-100, texto --ob-blue-700, pip --ob-blue. Hover: --ob-bg-warm. Fundo geral --ob-surface.

Motion. Transição de background a 120ms (--ob-ease) nos itens. A animação de expand/collapse (width) deve ser implementada no shell pai — o componente usa width calculado e não anima internamente para não conflitar com o layout do grid.

Responsivo. Em viewports < 768px, use o modo colapsado como padrão. Abaixo de 480px, converta para drawer (overlay) com backdrop clicável.

Versão mobile: SideNav não atende mobile diretamente — substitua por tab bar inferior ou drawer. Por isso não marca "versão mobile" na matriz.
