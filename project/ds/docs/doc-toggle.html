1 · Uso

Use para estados binários que aplicam na hora (notificações, tema). Se exigir confirmação, prefira Checkbox.

Faça

Aplicar a mudança imediatamente.

Evite

Toggle que só vale após "Salvar".

2 · Formatação

<Toggle checked={on} onChange={setOn} label="Notificações" size="sm" />
PropTipoPadrão
checkedboolean—
sizesm|mdmd

3 · Guia de conteúdo

  • Label descreve o que é ligado: "Modo escuro".
  • Sem "ativar/desativar" no label — o estado já comunica.

4 · Guia de design

Tokens. Trilho --ob-blue on / --ob-border off; knob branco.

Motion. Knob desliza 200ms --ob-ease.

Responsivo / mobile. Alvo de toque adequado; tamanho sm para densidade.
