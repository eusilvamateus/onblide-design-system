1 · Uso

Mostre enquanto dados carregam, no formato do que virá (linhas de texto, avatar, card). Reduz a percepção de espera.

✓ Faça

Espelhar o layout real do conteúdo.

✕ Evite

Spinner genérico quando o layout é previsível.

2 · Formatação

<Skeleton height={40} circle />

width / heightnumber|string100% / 16

3 · Guia de conteúdo

Sem texto — é puramente visual. (não marca guia de conteúdo na matriz)

4 · Guia de design

Tokens. Gradiente entre --ob-bg-alt e --ob-border — adapta a light/dark.

Motion. Shimmer de 1.4s em loop (ob-shimmer).

Responsivo / mobile. Dimensões fluidas; acompanha o container.
