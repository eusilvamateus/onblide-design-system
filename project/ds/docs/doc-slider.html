Slider doc

Controle de entrada contínua ou discreta para valores numéricos. Permite seleção de um único valor ou de um intervalo (range). Compõe com Input para entrada precisa e com ProgressBar para exibição do resultado.

1 · Uso

Use o Slider quando o valor exato for menos importante do que a sensação de posição relativa — volume, brilho, filtro de distância, prioridade. Para valores onde a precisão importa, ofereça um Input numérico ao lado.

Modos

  • Single — um thumb, um valor. O mais comum.
  • Range — dois thumbs, define um intervalo (ex: faixa de preço, datas relativas).
Faça

Use tones semânticos: verde quando o valor indica saúde, laranja para alerta, vermelho para limite crítico — comunicam estado sem rótulo adicional.

Evite

Usar Slider para selecionar entre poucos itens discretos (≤5). Prefira RadioGroup ou Segmented control — a posição relativa não agrega valor.

Composição com outros componentes

  • Input numérico ao lado para entrada precisa quando o step é fino.
  • ProgressBar para exibir graficamente o resultado do valor escolhido.
  • Tooltip sobre o thumb para mostrar o valor sem ocupar espaço no layout.

3 · Guia de conteúdo

  • Label: substantivo curto. "Volume", "Prioridade", "Distância máxima".
  • Hint: instrução de interação. "Arraste ou use as teclas de seta."
  • Valor exibido (showValue): numérico com unidade se necessário — "40%", "R$ 200 – R$ 500", "2,5 km".
  • Error: objetivo. "Valor fora do intervalo permitido." — nunca código técnico.
  • Marks: exiba rótulos de extremos (min/max) quando a escala não é óbvia.

4 · Guia de design

Tokens. Trilha vazia --ob-bg-alt (5px, radius 999). Preenchimento na cor do tone (--ob-blue padrão). Thumb: --ob-surface com borda 2px na cor do tone, sombra --ob-shadow-sm, 20×20px. Focus ring: 0 0 0 4px var(--ob-focus-ring). Valor: --ob-font-mono peso 700 na cor do tone.

Tones. Use tone para comunicar estado semântico. Ex: slider de prioridade — verde (baixa), laranja (média), vermelho (crítica). O tone muda a cor do preenchimento, do thumb e do valor exibido — consistente com Alert, Toast e ProgressBar via OB_TONES.

Motion. Preenchimento da trilha: transição de 80ms (none durante drag para responsividade). Focus ring no thumb: 150ms --ob-ease.

Mobile. Hit target mínimo de 44px de altura total (thumb 20px + área de toque). O evento de pointer capture garante que o drag continue mesmo saindo do thumb.

Acessibilidade. O thumb tem role="slider" com aria-valuemin/max/now. Suporte a teclado: ←/→ = 1 step; Shift+←/→ = 10 steps; Home/End = min/max.

Slider vs Input numérico: quando a precisão do valor final importa mais do que a sensação de posição relativa, combine um Slider com um Input ao lado — o Slider para navegação rápida, o Input para entrada exata.
