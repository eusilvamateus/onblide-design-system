Foundation · Transparência

Opacity Scale

Opacidade controla a transparência de um elemento — 0 é invisível, 1 é totalmente opaco. Na Onblide, a opacidade tem uso restrito e semântico: desabilitar, sobrepor, indicar foco e criar scrims.

1 · Escala numérica

A escala completa de 0 a 1. Os stops relevantes para interface são marcados com seu token semântico.

Val Token % Demo Uso semântico
0 — 0%
Totalmente invisível — display:none é preferível
0.08 --ob-opacity-hover 8%
Hover overlay sobre cor sólida
0.32 --ob-opacity-focus 32%
Anel de foco (focus-ring alpha)
0.45 --ob-opacity-disabled 45%
Elemento desabilitado (opacity no pai)
0.45 --ob-opacity-scrim 45%
Backdrop de modal, drawer e sheets
0.75 --ob-opacity-strong 75%
Hover em links, ícone secundário ativo
1 — 100%
Totalmente opaco — padrão de todo elemento

2 · Tokens semânticos

Use sempre o token semântico — nunca um valor numérico de opacidade hardcoded em componentes.

TokenValorContextoOnde usar
--ob-opacity-hover 0.08 Hover Overlay rgba sobre botão colorido no hover
--ob-opacity-focus 0.32 Foco Alpha do --ob-focus-ring
--ob-opacity-disabled 0.45 Desabilitado opacity: var(--ob-opacity-disabled) no elemento pai
--ob-opacity-scrim 0.45 Backdrop Fundo de modal/drawer: rgba(20,20,20, var(--ob-opacity-scrim))
--ob-opacity-strong 0.75 Hover link a:hover { opacity: var(--ob-opacity-strong); }
Opacity vs color-mix: para tints de cor (fundo levemente colorido), prefira color-mix(in srgb, var(--ob-blue) 12%, transparent) em vez de opacity no elemento — color-mix não afeta filhos.

4 · Instruções de uso

  • Disabled: aplique opacity: var(--ob-opacity-disabled) no elemento pai. Todos os filhos ficam translúcidos uniformemente. Combine com pointer-events: none e cursor: not-allowed.
  • Scrim: use rgba(20, 20, 20, var(--ob-opacity-scrim)) para backdrop. Em dark mode o backdrop é mais opaco — o token já está wired por tema no CSS.
  • Hover em elementos coloridos: não mude a cor de fundo no hover — sobreponha rgba(255,255,255, var(--ob-opacity-hover)) ou rgba(0,0,0, var(--ob-opacity-hover)) via pseudo-elemento ::after.
  • Nunca use opacidade para tipografia: use os tokens de cor --ob-fg-soft ou --ob-fg-mute. Opacity em texto afeta readability em fundos coloridos.
