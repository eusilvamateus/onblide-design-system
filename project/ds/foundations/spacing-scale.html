Spacing Scale

Quinze passos de 2 a 128 px. O nome de cada token é o valor dele: --ob-space-8 vale 8px. Todo espaçamento da interface (gap, padding, margin) vem desta escala, e um teste automático do pacote recusa qualquer número fora dela.

Instruções de uso

  • Use sempre um token, nunca o número solto: padding: var(--ob-space-20), não padding: 20px.
  • Os passos de 2, 6, 10 e 20px existem para o interior dos componentes (chips, badges, campos). Entre blocos de uma tela, prefira os passos de 8 em diante e os apelidos.
  • Prefira gap (flex/grid) a margin entre irmãos — é mais robusto a reordenações de DOM.
  • Espaçamentos horizontais e verticais do mesmo contexto devem vir da mesma etapa da escala.
  • Nunca use --ob-space-128 (128px) dentro de componentes — é reservado a layout macro.
  • Tamanhos de touch target (mobile): mínimo 44px. Use --ob-space-48 (48px) como padrão para altura de botões e inputs em mobile.
✓ Faça

Cards com padding: var(--ob-pad-card). Grid de cards com gap: var(--ob-gap-md).

✕ Evite

Valores fora da escala: padding: 18px, gap: 14px. Quebram a consistência visual sem ninguém perceber.

Debugging de espaçamento: se um valor não cabe em nenhum token da escala, é um sinal de que o layout precisa ser revisado — não de que a escala precisa de um novo passo.
