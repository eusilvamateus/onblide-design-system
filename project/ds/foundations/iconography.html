Iconography doc

Ícones são elementos auxiliares — facilitam o reconhecimento de funções e reduzem carga cognitiva. A biblioteca única é Phosphor Icons; nenhuma outra fonte de ícones é permitida.

1 · Uso

Ícones acompanham texto na quase totalidade dos casos. Apenas ícones classificados como "conhecidos" podem aparecer sem rótulo — aqueles com significado universal independente de idioma ou contexto.

Quando usar sem texto standalone

✓ Faça

Ícone md (20 px) sempre com rótulo. Gap fixo de 8 px. Cor herda do contexto via currentColor.

✕ Evite

Ícones ambíguos sem texto. Reserve standalone exclusivamente para os "Ícones Conhecidos" listados acima.

Composição com outros componentes

  • Button — ícone à esquerda do rótulo, gap 8 px, mesmo peso.
  • Badge — ícone sm (16 px) ao lado do texto da badge.
  • Alert / Toast — ícone md (20 px) alinhado ao topo do texto.
  • SideNav — ícone lg (24 px) com rótulo no modo expandido.

Brand logos (Spotify, Slack, etc.) não estão incluídos no webfont CSS. Reproduza-os como SVG fiel ao estilo Phosphor até migração para @phosphor-icons/react.

3 · Álbum principal

Conjunto aprovado para uso no produto. Não misture com outras bibliotecas de ícones.

4 · Guia de design

Biblioteca única. Phosphor Icons (peso Regular). Nunca misture Lucide, Feather, Material, Heroicons ou Font Awesome.

Tokens. Tamanho via variável semântica (sm 16 px, md 20 px, lg 24 px, xl 32 px). Cor via currentColor — herda do contexto, não use hexadecimal inline.

Fill. Use somente em estados ativos (ex: botão primário preenchido). Em ações secundárias, sempre Regular.

✓ Faça

Ícone lg (24 px) para SideNav; md (20 px) para ações e alertas; sm (16 px) para badges e inline de texto.

✕ Evite

Tamanhos e gaps inconsistentes (ex: 22 px + 5 px de gap). Sempre use os tamanhos tokenizados.

Acessibilidade: ícones decorativos devem ter aria-hidden="true". Ícones standalone (conhecidos, sem texto) precisam de aria-label descritivo.
