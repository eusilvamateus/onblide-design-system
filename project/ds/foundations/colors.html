Color System

Os tokens de cor são a camada mais crítica do design system. Organizam-se em três níveis: base (valores brutos da paleta), semânticos (intenção de uso) e feedback (estados de sistema). Sempre use o nível semântico em componentes.

4 · Instruções de uso

  • Sempre use o token semântico em componentes. Nunca escreva #0a4ee4 diretamente num componente.
  • Use o token de base (--ob-blue) somente em swatches de documentação, não em UI.
  • Texto sobre fundo colorido: sempre --ob-fg-on-color (#fff) — nunca escolha manualmente.
  • Nunca use verde para informação neutra ou cinza para sucesso — a semântica de cor é universal.
  • Fundo de componente: --ob-surface (não --ob-bg) — --ob-bg é para página.
✓ Faça

color: var(--ob-fg-strong) em títulos. background: var(--ob-surface) em cards. border-color: var(--ob-border) em todos os controles.

✕ Evite

Hardcoded: color: #2a2a2a. Se o tema mudar, o componente fica quebrado silenciosamente.
