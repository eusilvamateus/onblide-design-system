Border Radius

Oito etapas de arredondamento constroem a linguagem de forma da Onblide — do micro ajuste de 4 px ao círculo perfeito. A personalidade é suave, nunca aguda: o raio mínimo já visível em todo controle interativo é --ob-r-sm (8 px).

Aliases semânticos

Três aliases mapeiam intenção de uso, não geometria. Prefira-os em implementação de componentes para facilitar mudanças globais.

AliasAponta paraValorFamília de componentes
--ob-r-control --ob-r-sm 8 px Inputs, Buttons, Checkboxes, Selects, Code Input
--ob-r-surface --ob-r-md 12 px Cards, Dropdowns, Tabs panel, Table container
--ob-r-overlay --ob-r-lg 16 px Modal, Drawer, Toast, Alert
--ob-r-pill (999px) arredonda as pontas de qualquer elemento comprido; --ob-r-circle (50%) faz um círculo de um elemento quadrado. Nenhum dos dois tem apelido, porque o nome já diz o formato.

Instruções de uso

  • Use sempre um token — nunca valores hardcoded como border-radius: 10px.
  • Mantenha consistência dentro da mesma família: todos os botões da tela com --ob-r-control.
  • Não misture raios em lados opostos do mesmo elemento (top-left diferente de bottom-right) sem razão funcional — ex: dropdown que abre abaixo pode zerear o raio do lado que se encosta ao trigger.
  • Imagens dentro de cards: use border-radius igual ao do card menos 1 nível se a imagem estiver no interior (overflow: hidden no pai resolve).
✓ Faça

Use --ob-r-surface em todos os cards. Mude o valor do alias em um lugar e todos os cards atualizam.

✕ Evite

Misturar border-radius: 14px hardcoded com tokens — impede refactoring e cria inconsistência silenciosa.
