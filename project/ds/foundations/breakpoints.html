Breakpoints & Grid

Quatro breakpoints, mobile-first. Cada um é a largura mínima de uma faixa de tela: o estilo base vale no celular, e cada breakpoint acrescenta o que muda a partir dele.

Uso em CSS

Escreva o estilo do celular primeiro e acrescente as mudanças com min-width. Nunca use max-width nem um número fora da escala. Variáveis CSS não funcionam dentro de @media, então o número vai literal.

.lista { grid-template-columns: 1fr; }
@media (min-width: 768px)  { .lista { grid-template-columns: 1fr 1fr; } }
@media (min-width: 1024px) { .lista { grid-template-columns: repeat(3, 1fr); } }

Uso em JavaScript

import { BREAKPOINTS, mediaQuery, useBreakpoint } from '@onblide/ui';

BREAKPOINTS.md;        // 1024
mediaQuery('md');      // "(min-width: 1024px)"

const { current, atLeast } = useBreakpoint();
current;               // "base" | "sm" | "md" | "lg" | "xl"
atLeast('md');         // true a partir de 1024px

3 · Spans de coluna

A largura de um elemento é o número de colunas que ele ocupa. Os spans abaixo usam a grade de 12 colunas (md em diante); em sm a grade tem 8 e em base, 4.

Implementação CSS

.pagina {
  max-width: var(--ob-container-page);
  margin: 0 auto;
  padding: 0 var(--ob-grid-margin);
}
.grade {
  display: grid;
  grid-template-columns: repeat(var(--ob-grid-cols), 1fr);
  gap: var(--ob-grid-gutter);
}
@media (min-width: 768px) {
  .pagina { padding: 0 var(--ob-grid-margin-sm); }
  .grade  { grid-template-columns: repeat(var(--ob-grid-cols-sm), 1fr); gap: var(--ob-grid-gutter-sm); }
}
@media (min-width: 1024px) {
  .pagina { padding: 0 var(--ob-grid-margin-md); }
  .grade  { grid-template-columns: repeat(var(--ob-grid-cols-md), 1fr); gap: var(--ob-grid-gutter-md); }
}

5 · Regras

  • Mobile-first: o estilo base é o do celular; cada @media (min-width: …) acrescenta o que muda.
  • Só os valores da escala: 768, 1024, 1280 e 1440. Um teste automático do pacote recusa qualquer outro número e qualquer max-width.
  • A grade organiza a página, não o interior de cards e formulários; ali valem os tokens de espaçamento (--ob-gap-*, --ob-pad-card).
✓ Faça

Comece com grid-column: span 4 (largura total no celular) e passe para span 6 a partir de md.

✕ Evite

Inventar um ponto de quebra (600px, 900px) para um caso de uma tela só.
