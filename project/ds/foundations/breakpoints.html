Breakpoints & Grid

Grades de layout organizam o conteúdo em colunas responsivas que se adaptam automaticamente por breakpoint. Cada ponto de quebra define colunas, gutter e margem — o comportamento visual muda, os princípios permanecem.

1 · Breakpoints

Sistema de 5 pontos de quebra, mobile-first. Cada breakpoint representa o início da faixa — um layout que começa em md (1024px) vale para 1024px em diante até o próximo.

CSS Variables não funcionam em @media queries. Os tokens de breakpoint são valores de referência para documentação e lógica JavaScript. Em CSS, use os valores literais: @media (min-width: 768px).

Uso em CSS e JS

/* CSS — use os valores literais */
@media (min-width: 768px) { /* sm → tablet */ }
@media (min-width: 1024px) { /* md → desktop */ }

/* JavaScript — referencie os tokens via getComputedStyle */
const bp = getComputedStyle(document.documentElement)
  .getPropertyValue('--ob-bp-sm').trim(); // "768px"

2 · Grade de layout

A grade muda de configuração em três faixas: mobile, tablet e desktop. Todas têm em comum: colunas, gutter (espaço entre colunas) e margem (espaço lateral externo).

Faixa Breakpoints Colunas Gutter Margem Max-width
Mobile < 480px 4 16px 16px 100%
Tablet 480px – 1023px 8 24px 32px 100%

3 · Spans de coluna

A largura de um elemento é definida pelo número de colunas que ele ocupa. Os spans abaixo se referem ao grid de desktop (12 colunas) — adapte proporcionalmente para tablet (8) e mobile (4).

Span% do containerUso típicoVisual
2 / 12 16,6% Sidebar estreita, ícone + label
3 / 12 25% Sidebar padrão, filtros
4 / 12 33,3% Card em grade de 3, coluna auxiliar
6 / 12 50% Dois cards lado a lado, formulário split
8 / 12 66,6% Conteúdo principal com sidebar
9 / 12 75% Leitura longa, artigo + nav lateral
12 / 12 100% Full-width: hero, tabela, cabeçalho

Implementação CSS

/* Container responsivo */
.page-container {
  max-width: var(--ob-max-w-page);  /* 1280px */
  margin: 0 auto;
  padding: 0 var(--ob-grid-margin-desktop);
}

@media (max-width: 1023px) {
  .page-container { padding: 0 var(--ob-grid-margin-tablet); }
}
@media (max-width: 479px) {
  .page-container { padding: 0 var(--ob-grid-margin-mobile); }
}

/* Grade de 12 colunas */
.grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: var(--ob-grid-gutter-desktop);
}
@media (max-width: 1023px) {
  .grid {
    grid-template-columns: repeat(8, 1fr);
    gap: var(--ob-grid-gutter-tablet);
  }
}
@media (max-width: 479px) {
  .grid {
    grid-template-columns: repeat(4, 1fr);
    gap: var(--ob-grid-gutter-mobile);
  }
}

5 · Instruções de uso

  • Use sempre a grade para organizar conteúdo de página — nunca posicione elementos com position: absolute para layout estrutural.
  • O gutter define o espaço entre colunas. O espaço dentro do conteúdo usa os tokens de spacing (--ob-gap-*, --ob-pad-card).
  • Elementos fluidos (sem largura fixa) esticam para preencher as colunas disponíveis. Use spans fixos apenas para elementos que precisam de proporção específica.
  • Em mobile (4 colunas), a maioria dos elementos ocupa 4/4 (full-width). Reserve spans menores para ações secundárias em linha.
  • Não use a grade para micro-layout interno de componentes — a grade é para estrutura de página, não para dentro de cards ou formulários.
✓ Faça

Use grid-column: span 6 para dois cards lado a lado no desktop. No tablet, sobrescreva para span 8 (full).

✕ Evite

Criar um número de colunas diferente dos tokens (ex: 10-col custom). Quebraria a consistência responsiva.

Tokens de breakpoint em @media: CSS não suporta variáveis em media queries. Use os valores numéricos literais (480, 768, 1024, 1280, 1440). Os tokens existem como referência de documentação e para uso em JavaScript.
