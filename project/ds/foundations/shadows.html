Foundation · Elevação

Box Shadow

Sombras comunicam elevação — a distância percebida entre camadas da interface. O sistema é contido e difuso: evita sombras dramáticas para não competir com o conteúdo.

Escala de tokens

--ob-shadow-xs
0 1px 2px rgba(20,20,20,.04)
Distinção mínima. Card em superfície alt.
--ob-shadow-sm
0 1px 3px .05 + 0 1px 2px .03
Leve elevação. Chips, avatares, inputs focus.
--ob-shadow-md
0 4px 12px .06 + 0 1px 3px .04
Elevação clara. Dropdowns, tooltips, popovers.
--ob-shadow-lg
0 12px 28px .08 + 0 4px 8px .04
Alta elevação. Modais, drawers, sheets.
--ob-shadow-pop
0 8px 24px rgba(10,78,228,.18)
Acento de marca. Botão CTA primário, active states.
Nível 0
sem sombra
Flat. Tabelas, elementos inline, ítens de lista.

Modelo de elevação

Cada nível de elevação corresponde a uma camada semântica da interface. Nunca pule níveis.

N Token Demo Componentes
0 nenhuma
Linhas de tabela, itens de lista, campos de form
1 --ob-shadow-xs
Cards em superfície alternada
2 --ob-shadow-sm
Cards em branco, chips, avatares
3 --ob-shadow-md
Dropdowns, tooltips, popovers
4 --ob-shadow-lg
Modal, Drawer, Toast, Sheets
★ --ob-shadow-pop
Botão CTA primário ativo, elementos de destaque
Regra dos níveis: a camada mais alta de sobreposição na tela deve ter a sombra mais pesada. Dropdown (nível 3) sempre acima de um Card (nível 2).

Tema escuro

No tema escuro, as sombras têm opacidade maior porque o contraste de elevação é menor sobre fundos escuros.

Os tokens semânticos (--ob-shadow-*) já invertem automaticamente com [data-theme="dark"]. Nunca hardcode os valores rgba.

Instruções de uso

  • Sempre use os tokens — nunca escreva valores box-shadow hardcoded.
  • Nunca aplique sombra e borda ao mesmo elemento — escolha um. Borda para definição de forma; sombra para elevação.
  • --ob-shadow-pop é exclusivo de elementos de ação primária (botão CTA). Não use em cards ou containers.
  • Não empilhe sombras (múltiplos box-shadow de tokens diferentes) no mesmo elemento.
✓ Faça

Botão primário com --ob-shadow-pop. Modal com --ob-shadow-lg. Card com --ob-shadow-sm.

✕ Evite

Sombra E borda no mesmo card. Modal com --ob-shadow-sm (muito fraco para overlay).
